# CheckEat-Business

## 2025 채용연계형 부트캠프 - 최종 프로젝트

CheckEat - Business 은 OCR 기반 사업자등록증 인증과 메뉴 재료 추출·관리를 통해 매장정보를 손쉽게 제공할 수 있는 애플리케이션
사업자가 메뉴 재료 정보를 쉽고 간편하게 제공할 수 있도록 만든 앱

<br/>
<br/>
Period : 25.06.30 ~ 08.22
<br/>

<br/>

### 기능
- 로그인 기능
- 마이페이지 기능
- 사업자등록증 OCR 인식으로 간편 등록
- 메뉴사진 OCR과 AI로 재료 자동 추출 및 등록
- 메뉴수정·삭제·추가 가능
